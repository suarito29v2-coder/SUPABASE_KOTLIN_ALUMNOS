## 📌 Descripción del proyecto

Alumnos UTEQ es una aplicación móvil desarrollada en Android Studio que permite consultar información de estudiantes de la Universidad Técnica Estatal de Quevedo.

La aplicación utiliza Kotlin para su funcionamiento, XML para el diseño de la interfaz y Supabase para almacenar y consultar los datos de los estudiantes.

Se implementó ConstraintLayout para organizar los elementos visuales y facilitar su adaptación a diferentes tamaños de pantalla.

## 🎯 Objetivo

Desarrollar una interfaz móvil responsiva utilizando XML y ConstraintLayout, que permita consultar y visualizar información académica de estudiantes mediante una conexión con Supabase.

## 🛠️ Tecnologías utilizadas

- Android Studio
- Kotlin
- XML
- ConstraintLayout
- Material Design
- Supabase
- GitHub

## 📲 Componentes de la interfaz

- **ImageView:** muestra el logotipo UTEQ.
- **TextView:** presenta títulos e información.
- **MaterialButton:** permite actualizar la lista.
- **MaterialCardView:** organiza los datos en una tarjeta.
- **NestedScrollView:** permite desplazarse por los estudiantes.
- **ProgressBar:** indica la carga de datos.
- **ConstraintLayout:** organiza la interfaz mediante restricciones.

## 📐 Diseño responsivo

El diseño utiliza restricciones, márgenes y dimensiones adaptables para mejorar la visualización en diferentes dispositivos Android.

Se realizaron pruebas utilizando los emuladores Medium Phone y Pixel 7 con Android API 37.

## ⚙️ Funcionamiento

1. El usuario abre la aplicación Alumnos UTEQ.
2. Se presenta la interfaz principal.
3. La aplicación consulta los datos de Supabase.
4. El botón "Actualizar lista" permite repetir la consulta.
5. Los estudiantes aparecen dentro de una tarjeta con desplazamiento vertical.

## ✅ Resultados obtenidos
